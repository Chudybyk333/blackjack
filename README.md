Simple blackjack game written in c++ with sfml libraries for UI. Game has all the features found in a traditional blackjack game.

App overview:
Game starts immidietly with 10000 units which you can bet. You can either write how much do you want to bet or use chips as buttons that add a certain amount. In the game there are 2 decks at the start and when there are less than 20 cards left in the shoe after a hand the decks are shoufled. Game alows you to hit, stand, double down or split like in a traditional blackjack game. As a bonus blackjack pays 5:1. Hovewer you can only play on one spot.
